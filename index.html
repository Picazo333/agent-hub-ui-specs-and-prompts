Skills

Capabilities that can be attached to an agent.

What is a skill?

A skill is a capability that can be attached to an agent — for example browsing the web, reading documents, or managing a calendar. A skill does not run by itself. It becomes available only when an agent has it enabled and a contract includes it.

Web Browse

Opens public web pages and extracts visible text. It cannot log in or submit forms.

Enabled on 3 agents

Document Read

Reads PDF and text documents supplied by the client and quotes passages with page numbers.

Enabled on 4 agents

Calendar

Reads busy time and proposes events. It cannot invite attendees.

Enabled on 2 agents

Email Draft

Drafts email text. Sending stays with the client.

Enabled on 1 agents

Spreadsheet

Reads tabular files and computes sums, averages, and mismatches.

Enabled on 1 agents

Policy Check

Scores a document against a fixed checklist and returns pass or fail per item.

Enabled on 1 agents
